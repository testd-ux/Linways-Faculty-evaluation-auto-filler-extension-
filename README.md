# Linways-Faculty-evaluation-auto-filler-extension-

Install in Brave

1. Open `brave://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Select the extracted folder that contains `manifest.json`.
5. Open the form and click the extension icon, then **Fill this page**.

It fills up to 10 groups. Groups with five options are preferred. Pages built with custom controls or unusual markup may not be recognized automatically; in that case, a screenshot and the page URL can help adapt it. The extension never clicks a submit button.
